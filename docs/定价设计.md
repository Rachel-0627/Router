# 定价设计(定案版)

## 一、定价公式

```
售价 = Anthropic list price × 40%    (便宜 60%)
成本 = 上游 VIP 分组价格 ÷ 7.2       (保守汇率,实际约 7.1)
```

倍率写在环境变量 `PRICE_RATIO_OF_OFFICIAL=0.40`,调价不改代码。

### 为什么是 4 折,不是 3 折

英文用户**能接触到**的竞争对手只有三个:

| 竞争对手 | 价格 | 英文用户能用吗 |
|---|---|---|
| Anthropic 官方 | 100% | ✅ |
| OpenRouter | ~105%(官方价 + 加价) | ✅ |
| 其他中国中转站 | 很便宜 | ❌ 中文界面、支付宝、不敢信 |

**可及竞争对手都在 100% 附近。** 4 折已经是"便宜 60%",冲击力足够;
再打到 3 折只是从便宜 60% 变成便宜 70%,说服力提升很小,却少赚 5 个点毛利。

| 倍率 | 对用户 | 平均进货毛利 | 净利率 |
|---|---|---|---|
| 3 折 | 便宜 70% | 81.2% | 76.3% |
| **4 折** ⭐ | **便宜 60%** | **85.9%** | **81.1%** |
| 5 折 | 便宜 50% | 88.7% | 83.9% |

选 4 折还有两个好处:**留了降价空间**(以后可促销打 3 折);**价格不至于低到引起支付平台怀疑**。

## 四、充值档位

| 档位 | 到账额度 | 支付手续费率 |
|---|---|---|
| $20 | $20 | 5.9% |
| **$50** ⭐ | $50 | **4.7%** ← 默认选中,标 "Most Popular" |
| $200 | $200 | 4.1% |
| 自定义 | 最低 $20 | — |

**充多少用多少,无任何赠送。**
**自动充值默认额度设 $50**(Creem 按笔收 $0.40 固定费,小额扣款会累加成大笔)。

⚠️ **最低 $20 不能再低**:$10 档手续费 7.9%,$5 档高达 11.9%。

## 五、不做赠送和免费额度的决定

| 项目 | 决定 | 原因 |
|---|---|---|
| 新用户免费额度 | ❌ **不做** | — |
| 充值赠送 | ❌ **不做** | 会产生退款漏洞(见下),且规则复杂化 |

### 不做赠送顺带解决的一个漏洞

如果做 "充$200送$20",会出现:
- 用户充 $200 得 $220 额度
- 只用掉赠送的 $20,然后申请退款
- 若规则是"未消费额度全额退" → 你亏 $11
- 若规则是"赠送优先消耗" → 同样亏
- 只有"付费优先消耗 + 赠送永不折现"才不亏,但要在数据库里维护两个额度桶

**不做赠送 = 一个额度桶,规则简单,零漏洞。**

## 六、退款政策(写进 Refund Policy 和结账页)

> **未消费额度,30 天内全额退款。已消费部分不退。**

因为没有赠送,规则就是这么一句话。

| 场景 | 退多少 | 你的净利 |
|---|---|---|
| 充 $200 未消费就退 | $200 | **-$8.20**(仅损失支付手续费) |
| 充 $200 用了 $50 退 | $150 | +$34.75 |
| 充 $200 用完 | $0 | +$163.60 |

**除了零消费退款的手续费,任何情况都不亏。**

⚠️ **监控滥用**:同一用户反复充值→退款,直接封号。

**为什么要主动给退款通道**:一次拒付要付 $20 手续费还计入拒付率,
**拒付率超 1% 会被支付平台踢掉**。主动退款永远比被拒付便宜。

## 七、调价触发条件

| 上游涨价 | 4折下毛利 | 动作 |
|---|---|---|
| 不涨 | 84.7% | — |
| 涨 1 倍 | 69.4% | 观察 |
| 涨 2 倍 | 54.1% | 观察 |
| 涨 3 倍 | 38.8% | ⚠️ 评估涨价 |
| 涨 5 倍 | 8.2% | 必须涨价 |

> **触发线:上游成本超过售价的 50% 时启动涨价评估。**
> 4 折比 3 折多扛一档涨价空间。

## 八、定价页呈现要点

1. **缓存价格必须单列** —— Claude Code 用户 90% 的 token 是缓存读
2. **划线对比** —— `$2.00` 旁边划掉的 `~~$5.00~~`
3. **放"一小时 $1.86 vs $4.65"** —— 比百分比直观十倍
4. ⚠️ 措辞用 **"list price"**,不写 "official Anthropic price"
5. ⚠️ 必须有一句披露:
   *"Model behavior may differ from first-party APIs. Optimized for coding agent workloads."*

## 九、技术实现

价格数据放 `lib/pricing/models.ts`:

```ts
type ModelPricing = {
  id: string                 // 对外模型 ID
  upstreamId: string         // 上游模型 ID
  displayName: string
  contextWindow: number
  listPrice:   { input, output, cacheRead, cacheWrite }  // USD / 1M
  upstreamCny: { input, output, cacheRead, cacheWrite }  // CNY / 1M (VIP组)
  ratioOverride?: number     // 预留,暂不用
}
```

- 售价由 `listPrice × 倍率` **算出来**,不硬编码
- 成本记录在案,用于毛利监控和调价预警
- **唯一计算入口**:`lib/pricing/calculate.ts`,别处不许自己算
